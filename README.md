# AI 整页翻译

> 本目录即浏览器「AI 整页翻译」扩展的源码。2026-10-20 从 `~/bid-ai/ai-translator-extension` 迁移至此并改名。
> 搬迁后需在 `chrome://extensions` 移除旧条目，重新「加载已解压的扩展程序」选择本目录。详见 `先看我.txt`。

## 划词翻译（1.1.0）

1. 在 Chrome 扩展管理页 `chrome://extensions` 找到本插件，点击重新加载；首次安装则开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。
2. 刷新要阅读的网页。
3. 选中文字，点击旁边的“译 翻译”，原地查看译文。沿用面板中配置的接口、模型和目标语言。
4. 点击“复制译文”可复制；点击卡片外或按 Esc 关闭。页面滚动或窗口缩放也会收起卡片。
5. 面板中的“划词翻译”开关默认开启，关闭后立即生效。

仅选中文字不会请求模型。支持单词、句子和段落，每次上限 12000 字符。输入框、可编辑区域和常见代码编辑器不触发。失败时可重试；等待 45 秒后显示超时。关闭卡片会忽略迟到结果，但已经发出的模型请求可能仍会完成并计费。剪贴板不可用时可手动选中译文复制。浏览器内部页面不支持脚本注入。

## 验证

`tests/selection.browser.cjs` 使用 Playwright 启动隔离的无头 Chrome，在真实 DOM 中执行源码，模拟 Chrome 扩展 API 和翻译响应；不会读取用户配置或调用付费模型。

```sh
NODE_PATH=/path/to/node_modules node tests/selection.browser.cjs
```

默认 Chrome 路径为 macOS 的 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`，可通过 `CHROME_PATH` 覆盖。

覆盖：选区触发但不请求、译文显示、复制、整页翻译隔离、Esc/点击外部关闭、编辑区域排除、失败重试、迟到响应、设置开关、重复注入清理、窄屏定位和销毁清理。此测试不等同于已安装扩展与真实服务的端到端验证。
